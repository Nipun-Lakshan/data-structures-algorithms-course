# 💻 IT 3007 - Data Structures and Algorithms

A collection of programming exercises, practical implementations and assignments completed as part of the **IT 3007 – Data Structures and Algorithms** course. This repository documents my learning progress and practical work in understanding fundamental data structures, algorithms, problem-solving techniques and algorithm analysis.

## 📚 Repository Contents

### 01. Assignment 01 – Time Complexity
Covers the fundamentals of algorithm analysis and time complexity.

### 02. Assignment 02 – Sorting Algorithms
Contains implementations and practical exercises related to sorting algorithms, including:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

Implementations include sorting in ascending and descending order where applicable.
